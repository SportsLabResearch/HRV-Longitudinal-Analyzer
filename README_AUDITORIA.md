# Auditoría del proyecto v1.4.1-a

Ejecutar desde el menú principal:

```bash
py main.py
```

Seleccionar:

```text
7. Auditoría del proyecto
```

La aplicación generará una carpeta dentro de:

```text
Resultados_Auditoria/
```

con:

- Informe Word `.docx`
- Informe Excel `.xlsx`
- Resumen `.txt`

No modifica el análisis OCR ni los datos del proyecto.
