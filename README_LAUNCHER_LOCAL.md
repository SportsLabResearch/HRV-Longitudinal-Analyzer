# Launcher local v1.4.4-a

Uso recomendado en Windows:

1. Descomprimir el proyecto.
2. Ejecutar `INICIAR_HRV_WINDOWS.bat`.
3. El launcher analiza ese ordenador.
4. Instala solo las dependencias Python que falten.
5. Lanza `main.py`.

No empaqueta librerías innecesarias dentro de un ejecutable pesado.
