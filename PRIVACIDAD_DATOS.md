# Privacidad y publicación de datos

Este repositorio distribuye únicamente código, documentación y estructuras de
carpetas vacías.

No deben publicarse:

- imágenes originales de participantes;
- copias seudonimizadas de esas imágenes;
- archivos de correspondencia entre nombres y códigos;
- informes, hojas de cálculo o bases de datos generadas durante el análisis;
- archivos temporales, ejecutables o paquetes de distribución anteriores.

Antes de compartir un conjunto de datos se requiere una revisión específica del
contenido visible y de los metadatos de cada archivo, además de la base jurídica,
el consentimiento y las condiciones éticas aplicables al estudio.
