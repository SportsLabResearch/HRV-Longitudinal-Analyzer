# Tests básicos del proyecto

Esta carpeta contiene las comprobaciones automáticas mínimas para cerrar la versión v1.4.1-a:

- estructura principal del proyecto;
- compilación de archivos Python;
- funcionamiento básico del módulo de auditoría;
- generación de resultados de auditoría.

Estos tests están pensados para apoyar el cierre de versión, no para modificar el análisis OCR.
