# Manual de usuario

## Objetivo
Usar HRV-Longitudinal-Analyzer para analizar registros longitudinales de HRV.

## Flujo básico
1. Copiar imágenes o datos en `datos/`.
2. Ejecutar `python main.py`.
3. Seleccionar participante: uno, varios, intervalo o todos.
4. Elegir tipo de informe.
5. Revisar los resultados generados.
