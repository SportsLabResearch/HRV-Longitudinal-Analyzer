# Scientific Validation Framework (SVF)

Este directorio reúne la validación técnica y científica del software.

## Estructura

- `01_Technical/`: comprobaciones funcionales del software.
- `02_Scientific/`: validación científica de resultados y algoritmos.
- `03_Benchmark/`: comparación entre versiones.
- `04_Reproducibility/`: información para reproducir ejecuciones.
- `05_Datasets/`: conjuntos de datos usados en validación.
- `06_Publications/`: materiales orientados a artículos científicos.
- `07_Protocols/`: protocolos de validación.
- `Results/`: histórico de resultados generados por validaciones.

## Estado actual

Versión inicial: `v1.4.0-a`.

Objetivo de esta primera versión: crear la estructura base, el menú de validación y el dashboard de estado.
