# Installation

## Requirements

- Python 3.12+
- Windows
- Git

## Commands

    git clone https://github.com/SportsLabResearch/SportsLabResearch-rugby7-referee-spatial-analysis.git
    cd SportsLabResearch-rugby7-referee-spatial-analysis
    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt
