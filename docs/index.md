# HRV Longitudinal Analyzer

Software de investigación desarrollado por SportsLabResearch para el análisis longitudinal de la variabilidad de la frecuencia cardíaca (HRV) a partir de datos exportados desde Kubios HRV.

## Características

- Análisis longitudinal de HRV.
- Procesamiento automático de múltiples participantes.
- Generación de resultados y tablas.
- Exportación de informes.
- Orientado a investigación científica.
