    Manual de usuario¶

    Preparar las imágenes¶

    Dentro de Datos/ se crea una carpeta por participante. Conviene mantener el nombre original cuando contiene la fecha y hora del registro.

    Datos/
├── Participante_A/
│   ├── WhatsApp Image 2026-07-01 at 08.30.00.jpeg
│   └── WhatsApp Image 2026-07-02 at 08.25.00.jpeg
└── Participante_B/
    └── WhatsApp Image 2026-07-01 at 07.45.00.jpeg

    Iniciar el programa¶

    python main.py

    El menú ofrece análisis OCR, dashboard, gestor de participantes, validación científica, auditoría, distribución y control de los datos públicos.

    Seleccionar participantes¶

    Puede trabajarse con un participante, varios, un intervalo de códigos o todos. La selección activa se conserva para facilitar ejecuciones sucesivas.

    Seleccionar fechas¶

    Los límites son inclusivos. Con fecha final se aplica el mismo periodo a todos. Sin fecha final, cada participante se analiza hasta su última imagen con fecha válida. Una imagen sin fecha interpretable se excluye y registra como incidencia.

    Resultados¶

    Según el análisis pueden generarse una base Excel, informe Word y PDF, gráficos longitudinales, resumen del último lote y alarmas de calidad.

    Interpretación responsable¶

    LnRMSSD es el logaritmo natural de RMSSD válido y positivo. Las tendencias deben interpretarse considerando contexto, postura, hora, duración y artefactado. La aplicación no emite diagnósticos médicos.
