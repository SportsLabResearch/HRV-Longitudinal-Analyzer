# HRV-Longitudinal-Analyzer v1.4.0-a

## Objetivo

Primera implementación del Scientific Validation Framework (SVF).

## Incluye

- Estructura `Validation/`.
- Módulo `modules/validation.py`.
- Menú de validación científica.
- Dashboard de estado de validación.
- Estado básico de reproducibilidad.

## Prueba recomendada

```powershell
py main.py
```

Seleccionar:

```text
6. Validación científica (SVF)
```
