# HRV-Longitudinal-Analyzer v1.3.5 ESTABLE

Esta versión consolida la serie 1.3.x antes de iniciar cambios de arquitectura mayores.

## Incluye

- Dashboard del proyecto funcional.
- Estado del proyecto.
- Gestor de participantes.
- Selección activa de participantes.
- Integración básica de la selección activa con el análisis OCR.
- Versión actualizada a v1.3.5.

## Recomendación de prueba

Ejecutar desde la raíz del proyecto:

```powershell
py main.py
```

Comprobar:

1. Ejecutar análisis Kubios OCR.
2. Ver porcentaje del proyecto.
3. Dashboard del proyecto.
4. Gestor de participantes.
5. Ver selección activa.
0. Salir.
