# GitHub como repositorio vivo

Este repositorio debe contener todo lo que evoluciona con el proyecto:

- Código fuente
- Manuales
- Ejemplos
- Casos prácticos
- Issues
- Wiki
- Documentación
- Roadmap
- FAQ
- Vídeos mediante enlaces
- Presentaciones
- Changelog

GitHub será el punto central del desarrollo y la documentación del proyecto.
